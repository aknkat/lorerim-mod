# Estee Emerald Eyes 1.0.0 検査結果

実施日：2026-10-18。

## 合格した検査

- ESP：FormVersion 44、ESLフラグ、非ローカライズ、Skyrim.esmだけを必須マスターに指定。
- 新規レコードはTXST 801、HDPT 800、FLST 802の3件。既存レコード上書き0、スクリプト0。NPC・種族・魔法などのレコードは含まれない。
- HDPTはPlayable/Male/Eyes、専用TXSTと専用FLSTへ解決。FLSTは通常/吸血鬼カジートだけを列挙。
- 元HDPT/TXSTと比較し、HDPTのEDID/FULL/TNAM/RNAMとTXSTのEDID/TX00以外はバイト一致。モデル、TRI、法線画像、反射画像、TXSTフラグは元の設定を維持。
- 元画像をPNGにデコードしたデータと比較して、圧縮前画像のアルファは全ピクセル一致。HSL明度を表す各画素の最大RGB値と最小RGB値の和も全ピクセル一致。元の明度模様・瞳孔・輪郭を維持。
- 明るい虹彩画素の平均色相は154.334度、基準色#2EDB91の色相は154.335度。単色の塗りつぶしやゲーム画面上でのHEX一致を意味しない。
- DDS：1024×1024、BC7_UNORM、11ミップ、straight alpha、期待する各ミップ長とファイル総長を検査。
- Pillowによる独立したBC7デコードで11ミップすべて読み込み成功。最上位ミップと圧縮前画像の平均絶対誤差（0〜255）はR=0.04734、G=0.11228、B=0.08104、A=0.01704。アルファ最大誤差2。
- 別作者の @fcrick/tes-data 0.0.1 による読み戻し：TES4/TXST/HDPT/FLSTの4レコードすべてバイト一致の再シリアライズに成功。
- MO2用ZIP：許可した6ファイルだけ、重複パスなし、CRCと全ファイルのSHA256を確認。
- ソースZIP：元MODのBSA/ESPとユーザーのプリセットを含まない。CRCと全メンバーのチェックサムを確認。解凍したソースだけで再ビルドし、MO2用ZIPとソースZIPが両方ともバイト一致。
- 作業前からあるdist内の全配布物はSHA256が変わっていない。鋭敏な感覚の配布物は未変更。

## 未検証

Skyrimを起動した検査は実施していない。RaceMenuでの選択肢の列挙・表示番号、ゲームでの色と反射、まばたき、終了後ロードによる外見保持、吸血鬼化・治療・変身による外見切替は未検証。すべてのLoreRimプラグインやBSAの内容・最終勝者を検査したわけではない。構造検査をこれらの保証に読み替えない。
