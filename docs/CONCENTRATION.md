# 鋭敏な感覚（集中）0.2.9

カジートのプレイヤー向けに、**半径約5m・基礎消費50マジカ／秒**の生命探知を別魔法として追加します。**屋内は常時、屋外はゲーム内時刻19:00以上～翌6:00未満**に探知が有効です。通常の手持ち集中呪文で、押している間だけ探知します。既存のナイトアイと生命探知は変更しません。

**ファイルの構造・参照・配布物は検査済み。Skyrim／LoreRimでの実機動作は未検証です。** この版でロード後の不発が解決したと確認した意味ではありません。

## 0.2.9の変更

- 0.2.8の探知色#F58C73を **#FAAB76（RGB 250, 171, 118）** へ差し替えました。専用EFSHのRGB3キーのみ変更し、時間・範囲・消費・対象条件・手元の光なしを維持します。
- 色と版の表記、説明文を更新しました。テスト一式は再実行せず、0.2.8との差分と梱包時の構造チェックを確認しています。

## 0.2.4で導入した仕様

- 屋内は常時、屋外は**19:00以上～翌6:00未満（5:59台まで）**という条件をMGEFへ追加しました。屋内判定は探知対象ではなくPlayerRef自身を参照します。
- 範囲を約6mから**約5m**、基礎消費を25から**50マジカ／秒**へ変更し、**デイドラを除外**しました。死体・アンデッド・ドワーフ機械・NoDetectLifeの除外も維持します。
- 探知色は敵味方共通の **#E0C8B8（RGB 224, 200, 184）**。0.2.3の専用EFSH（ローカルID `802`）は同一です。粒子数・寿命・大きさ・透明度・合成・壁越し表示も変えていません。
- **手元の光・粒子は引き続きなし**（Casting Art未設定）。腕の装備・詠唱モーションと音はそのままです。
- 集中詠唱、経験値0、プレイヤーのカジート限定、魔法の名前・ESP名・全ローカルIDは維持します。クエスト・スクリプト・タイマー・強制詠唱停止処理は追加しません。

#FAAB76は現在のエフェクトに設定する入力色です。透明度・加算合成・背景・ENBなどにより、画面のピクセルが常にこの値になるわけではありません。構造検査は実機の描画や安全性の保証を代替しません。

専用EFSHは0.2.1で標準LifeDetectedEnemyの設定を別IDに複製したものです。Particle Grayscale Colorは解除、パレット参照は空で、直接RGBを使います。Editor IDは `LKSC_DetectionAmberShader` を維持し、現在の入力色は明るいアプリコット系の色です。共有のシェーダーや画像は上書きしません。

## 仕様

| 項目 | 内容 |
|---|---|
| 使用者 | プレイヤーの通常カジート／吸血鬼カジート |
| 魔法 | 鋭敏な感覚（集中） / Keen Senses (Concentration) |
| 分類・操作 | 変性に分類する通常の呪文。手に装備して通常の魔法と同じ操作で使用 |
| 範囲 | Area 17 feetと、PlayerRefから350ゲーム単位以下の距離条件。約5m |
| 持続 | 集中して詠唱している間。2秒固定ではありません |
| 消費 | 基礎50マジカ／秒。実消費はスキル・Perk・装備などの適用条件により変動し得ます |
| スキル成長 | この魔法のSkill Usage Multiplierは0。使用による変性経験値なし |
| 半減Perk | この呪文のHalf-cost Perkは未設定。対応Perkを要求しません |
| 再使用待ち | 独自クールダウンなし。時間・場所の条件と必要なマジカを満たせば探知可能 |
| 対象 | 周辺の生きたActor。死体・アンデッド・ドワーフ機械・デイドラ・NoDetectLife対象を除外 |
| 色 | 本MOD専用シェーダー、敵味方共通で#FAAB76 |
| 手元の発光 | Casting Artなし。腕の装備・詠唱動作は維持 |
| 屋内外・昼夜 | 屋内は常時。屋外はゲーム内時刻19:00以上または6:00未満。壁越しの探知を許可 |
| 付与 | コンソールでプレイヤーに手動付与。NPCへの配布・種族への自動追加なし |

経験値0は「他の魔法で変性を育てても消費に影響しない」という意味ではありません。この版は通常の変性呪文として処理されます。消費を常に50へ強制するフックや、鎧の詠唱ペナルティを打ち消す処理は加えていません。終盤でも残る主な制限は短い探知範囲です。

## 時間制限と朝を迎えた場合

判定は **PlayerRefが屋内 OR 時刻が19以上 OR 時刻が6未満**。たとえば屋外の5:59:59は有効、6:00と18:59:59は無効、19:00は有効です。ゲーム上の屋内扱いなら昼間の明るい部屋でも有効です。屋外扱いの特殊な地下空間には時刻制限が適用されます。

この時刻はユーザー指定の固定値です。ENBのSunriseTime／SunsetTime、天候・季節・画面上の照度を自動追跡せず、それらの設定も変更しません。

**探知が無効な時間帯でも、ボタンを押すと詠唱やマジカ消費が続く可能性があります。** 条件による探知の無効化と、魔法全体の強制停止は別です。屋外で朝6:00を迎えた後は、次の条件再評価で探知が無効になることを狙う構成ですが、切替の遅延・残光・継続消費は実機未検証です。詠唱を終える際は通常どおりボタンを離します。屋内では朝を迎えても時間条件による停止はありません。

## 依存と変更範囲

- ESLフラグ付きの `KhajiitKeenSensesConcentration.esp`。マスターは **Skyrim.esmのみ**。
- 新規SPEL 1件・MGEF 1件・EFSH 1件。既存レコードの上書き0件。
- 独自PSC・PEX・VMAD・クエスト・DLL・SKSEプラグインなし。追加のSKSEやAddress Libraryは不要。LoreRim自体の依存関係は通常どおり有効にします。
- ゲーム標準の音・キーワード・種族・粒子テクスチャは参照だけです。探知シェーダーは標準設定を本MOD固有の新規レコードに複製・調整します。標準レコード自体や第三者MODの勝者は上書きせず、画像・モデルは同梱しません。
- 対象環境：Skyrim SE 1.6.1170 / LoreRim v5.0.4.8 Default / Requiem / Cabbage ENB。これらの環境での動作確認済みという意味ではありません。

レコードの上書きがないことは、LoreRimの一般的な魔法補正・入力・アニメーション・DLLとの相互作用がないという保証ではありません。参照先テクスチャ等の最終勝者やENBによって表示も変わり得ます。

## 集中版0.2.0～0.2.4からの更新

ゲームを完全終了し、MO2で使用中の集中版MODを新ZIPで **Replace（置き換え）** してください。同名ESPを提供する集中版は1つだけ有効にします。ESP名と呪文IDを維持するため、追加済みの魔法を取得し直す必要はありません。更新後は新たに詠唱を始めて表示を確認します。

0.2.1で報告されたロード後の手への装備解除については、原因未特定です。0.2.4も装備・ロード処理を変更しておらず、この問題が直ったとは扱いません。

これは旧特殊能力版0.1.xとは別の更新です。旧0.1.xのセーブ情報は移行・削除しません。

## MO2への導入

1. ゲームを終了し、ZIPを保存します。ZIPは解凍せず、MO2左上の「アーカイブからMODをインストール」で選びます。
2. **新しいMODとして導入**し、左側のMODと右側の `KhajiitKeenSensesConcentration.esp` を有効にします。旧 `KhajiitKeenSenses.esp` のReplaceではありません。
3. MO2右側で、**新しいESPの**現在のMod Indexを確認します。
4. カジートのプレイヤーでコンソールから新魔法を追加します。

新ESPのIndexが **FE:ABC** なら、追加するコマンドは次です。

```text
player.addspell FEABC800
```

`ABC` は実際の新ESPの値に置き換えてください。これは例であり、過去の旧ESPの `FE:CF5` をそのまま使いません。新魔法のローカルIDは `800` です。

5. 魔法メニューの「変性」または「すべて」から **鋭敏な感覚（集中）** を手に装備します。
6. 普段の手持ち魔法と同じ操作で詠唱します。**特殊能力のY＋RTではありません。** このMODはキー設定を変更しません。

## 旧0.1.x・診断版を使ったセーブについて

新ESPは旧版のFormID・スクリプト・クエストを変更せず、移行やセーブ内の旧スクリプト情報の削除も行いません。**このZIPにスクリプトがないことと、既存セーブから旧版の情報が消えることは別です。**

旧版を含まない状態で確実に比較できるのは、旧版導入前のセーブまたは新規ゲームです。現在のセーブで試す場合、旧版の保存状態を保つために旧ESPを残したまま新ESPを追加することもできます。名前を区別し、新しい「鋭敏な感覚（集中）」を使用してください。旧特殊能力を外す場合は、**旧ESPの現在のIndex**とローカルID `800` を使って `player.removespell` します。旧クエストの停止・リセットや、他MODの無効化は要求しません。

旧版の無効化まで含むセーブ移行は未検証です。既存セーブから旧版を安全に完全除去できたと扱わないでください。

## 解除

詠唱を止め、新魔法を手から外します。新ESPが例のFE:ABCなら：

```text
player.removespell FEABC800
```

必要なら別名で保存し、ゲームを完全終了してからMO2で新MODを無効化します。この版には専用クエスト停止・タイマー解除の操作はありません。導入前の状態へ確実に戻す場合は、導入前のセーブを使います。

## 検査済み・未検証

0.2.9では色差分と梱包時の構造チェックを確認し、テスト一式・第三者読み戻しの再実行は省略しています。0.2.4で関連テスト19件と独立した読み戻しはすべて合格しました。条件テストは符号化された論理を検査するもので、ゲーム内で時刻境界を越える実測の代わりではありません。

制作環境で確認済みの項目：

- TES4／GRUP／SPEL／MGEF／EFSHのサイズ、SSE形式、ESL範囲、ローカル参照、マスター。
- 新規3レコードだけで既存レコードを上書きしないこと。
- SPELとMGEFがともにConcentration／Self、EitherHand、基礎消費50であること。
- 経験値倍率0、半減Perkなし、VMAD・クエスト・スクリプト・DLLがないこと。
- 公開済み0.2.3に対し、SPELは基礎消費・Area、MGEFは基礎消費・Spellmaking Area・条件だけを変更したこと。専用EFSHは同一であること。ヘッダー・説明文・マニフェストも現仕様へ更新。
- EFSHの400バイトの設定が標準探知の設定と一致し、変更はRGBカラー3キーと色モードのフラグだけであること。パレットパスは空で、既存の粒子テクスチャ参照を維持すること。
- 使用者のプレイヤー／種族条件と、探知対象の生死・デイドラ等のキーワード・距離条件の符号化。
- 屋外の5:59:59／6:00／18:59:59／19:00と日付またぎ、屋内の全時刻、PlayerRefを参照する屋内判定、時間条件が除外・距離条件を迂回しないこと。
- 日本語／英語の文字列参照、ZIP構造、CRCと全収録ファイルのSHA256。
- 第三者の `@fcrick/tes-data 0.0.1` によるESPの独立読み戻し。

未検証：

- ゲームが条件のSubjectを探知対象、Targetを術者として評価する実際の挙動。NPC・他種族・吸血鬼での結果。
- #FAAB76の実際の色味・見やすさ、パレットなしの粒子表示、手元発光の消失、他MODが追加する表示との組み合わせ。
- 実効半径約5m、移動時の追従、デイドラ等の除外対象、壁越しの表示、詠唱解除時の消失。
- 実際の屋内判定、特殊な地下・別ワールド、19:00／6:00を詠唱中に越えた場合の探知・残光・マジカ消費。
- LoreRimでの実消費、経験値が増えないこと、鎧・Perk・装備・入力MODとの組み合わせ。
- 通常操作での発動と、保存後にゲームを完全終了・再起動してロードした後の発動。
- 旧版入りセーブの移行と、MODを外した後の保存状態。

最初の実機確認は、生きた通常NPCの1～3mほど近くで、新魔法を手に装備して短く詠唱するところから行えます。その後、解除・消費・完全終了後のロードを確認します。範囲境界・除外対象の確認は、基本の発動が成立してからで構いません。スクリプトやDLLの設定変更は不要です。

LoreRimの保存・ロードの注意に従い、ロード前はゲームを完全終了・再起動してください。この版は独自の保存スクリプトや60秒タイマーを追加しませんが、ゲーム標準の魔法取得状態などはセーブに記録されます。
