# v0.1.4の実機確認

v0.1.3は通常の60秒間隔の使用はできたが、完全終了後でも待機中のセーブから復帰しないと報告された。v0.1.4は期限判定へ変更したが、**実機ではロード後の不発が続くとの報告があり未解決。** 下の保存復元試験をそのまま繰り返すより、先に発動経路を切り分ける。

現在の確認は、付け外し前、ロード後の通常画面で65秒以上待っても不発の状態で、主能力を直接Castする1回。IndexがFE:CFDのままなら `player.cast FECFD800 00000014 left` を入力して閉じる。これは装備入力を通さず、同じクールダウン制御を実行する。赤く表示されるか、表示されないか、コマンドエラーかを記録する。対象除外の検査へはまだ進めない。

## 更新

ゲームを終了し、MO2でv0.1.4を旧版へReplace。能力の再付与は不要。5件のFormID、VMAD参照と入力PEXは維持する。

旧版の待機フラグから残時間を復元することはできない。新しい期限のない旧セーブでは、更新後の初回だけクールダウンをリセットし、その発動から新方式の60秒を開始する。**旧セーブを更新して即使えることだけでは、新方式の保存復元を検証したことにならない。**

## 優先する確認

アンデッド等の対象検査より先に、今回失敗した待機中の保存・復元を確認する。進行用と別名の検証セーブを使う。

1. 生きたNPCの近くで、通常画面のY＋RTで一度発動する。
2. 発動から約15秒後に別名で保存。戦闘・重いスクリプト演出中・セル移動直後は避ける。
3. **ゲームを完全に終了・再起動**し、そのセーブをロードする。プレイ中に直接ロードしない。
4. パワーを付け外しせず、ロード後の通常画面で約45秒待って発動できること。時計の丸めや処理遅延の余裕を含め、初回確認はロード後50秒を目安にする。

失敗しても、付け外しで直るはずと決めつけない。更新直後の旧クールダウンのリセットと、新しい保存の復元を混同しない。残り秒数はこの環境の有効な効果に表示されないので、表示確認は求めない。

必要時は、ロード後に途中の再入力をしても期限が延びないこと、準備完了時に保存した場合の即時使用も確認する。連続保存は1～2分以上空ける。これらを最初からすべて繰り返す必要はない。

## 他の切り分け・対象確認（必要時のみ）

- 時間：0/30/65秒の通常発動。標準時計のメニュー・ポーズ・睡眠の影響は別途記録する。
- 距離：対象を選び `getdistance player`。Area 27 feet、距離条件560 units。移動とActorの原点差を記録する。
- 対象：通常NPC・動物は表示し、死体・アンデッド・Dwarven機械は除外。独自Actorのキーワード、NoDetectLife、吸血鬼Khajiitは別途確認する。
- 表示：敵味方共通、屋内外・昼夜・壁越し、自分の発光の有無、持続約2秒。
- Y長押しの「no items to interact with」とY＋RT連打時の音は発生元未特定。音だけで制限時間を判断しない。

ファイル側は制作環境で検査する。Raceの最終勝者や他MOD設定を一から調べ直す手順は不要。主能力800、入力MGEF801、探知MGEF802、内部魔法803、専用QUST804。送付されたロードオーダーのIndexはFE:CFDで、現在のMO2表示を優先する。

内部探知のみを確認する必要がある場合、Indexが同じなら `player.cast FECFD803 00000014 left`。これは制御を経由しないので、クールダウン検査には使わない。表示できている場合は追加実施不要。

## SSEEdit（必要時のみ）

v0.1.3と5レコードのフィールドは同じ。今回の変更はコントローラーPEX、ヘッダーの版説明と配布文書・マニフェスト。

- マスターSkyrim.esmのみ、上書き0件、MGEF 2件・SPEL 2件・QUST 1件。
- 主能力：Lesser Power、Self、Fire and Forget、Base Cost 0。入力効果Duration 1秒。
- 入力MGEF：Script、No Recast/No Death Dispel無効、Hide in UI有効、No Duration無効。VMADは旧3参照とCooldownControllerの4件。自己参照HasMagicEffect条件なし。
- 専用QUST：Start Game Enabledなし、Alias・ステージ・目標なし。スクリプトの参照はDetectionSpellと2種のKhajiitRace。
- 内部魔法：Magnitude 0、Area 27、Duration 2、Area Effect Ignores LOS有効。
- 探知MGEF：Detect Life、Actor Value None、FX Persist有効、Hit Shader `LifeDetectedEnemy [EFSH:000DC209]`。GetDistance PlayerRef <= 560と除外条件。探知側のNoRecastは60秒制限に使用しない。

解除はREADMEの本MOD専用手順に従う。保存・ロードの運用はユーザー提供の [LoreRim Safe Saving本文](https://v4.lorerim.com/home) を参照する。
