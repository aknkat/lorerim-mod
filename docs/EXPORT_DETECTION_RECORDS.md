# 動作した探知レコードを一括で取得する

ユーザー環境では標準の `VoiceAuraWhisper1 [SPEL:0008AFCC]` が赤く、8mより広い範囲で表示された。自作のprobe1は表示されなかった。標準能力の広い範囲は今回の比較用であり、自作MODの8m仕様が実現できたという意味ではない。また表示色は現在のレコードと描画環境に従い、青色とは限らない。

必要なのは、動作した標準レコードの内容と自作レコードの差である。制作環境にはゲーム本体とLoreRimのレコード実体がないため、一般的な項目名から推測して新しい診断ESPを配る方法はここで止める。

## 一度だけ行う取得手順

1. `LKS-Detection-Record-Export.zip` を **SSEEdit.exeがあるフォルダーへ展開**する。`Edit Scripts` フォルダー内に `LKS - Export detection records.pas` が入る構成。MO2へMODとして導入するZIPではない。
2. MO2からSSEEditを起動し、ゲームで使っているロードオーダーを読み込む。既にその状態で開いていれば開き直す必要はない。新しいパッチの生成・保存は不要。
3. 左側で任意のレコードを1件選び、右クリック → **Apply Script** → **LKS - Export detection records** → 実行する。能力やRaceを個別に探す必要はない。
4. 保存ダイアログでデスクトップなど分かる場所を選び、`LKS-detection-records.txt` を保存する。そのテキストをチャットへ添付する。

プラグインへの書き込みは行わず、出力するのはテキスト1ファイルだけ。既存のESPやESMの保存は不要。

## 取得内容と制限

- 実際に表示された標準能力、標準のDetect Life、その参照MGEF。
- 標準のFire and Forget探知MGEFと関連する4種のシェーダー。
- 上記のSkyrim.esm内の定義と、今回SSEEditに読み込んだプラグインの最終定義。
- 読み込まれていれば、KhajiitKeenSenses.espのSPEL/MGEFとその最終定義。
- 記録するのはレコード内の値と、そのレコードを持つプラグイン名。PCの認証情報やセーブファイルは取得しない。

ゲーム内動作と同じ最終定義を得るには、SSEEditに読み込むプラグインを実際のゲームと揃える。スクリプトはESP/ESMを編集するAPIを呼ばない。xEdit公開ソース・同梱スクリプトとのAPI照合を実施したが、制作環境ではSSEEdit本体での実行は未実施。

このデータから実装を修正する際も、新規レコードのみを持つESPと固有名スクリプトという構成を維持する。標準能力の広い範囲・アンデッド等の探知をそのまま代用するものではない。
