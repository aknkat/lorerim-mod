# v0.1.2：再使用待ちの自己参照条件を削除

## 実機報告

v0.1.1は近距離のNPCを赤く表示できた。待機後に再使用できる一方、0秒で発動・30秒で再入力・初回から65秒で再入力すると発動しなかったと報告された。再使用待ち・残り秒数は有効な効果に表示されないため、内部の時間値が再設定されたこと自体は観測できていない。

入力はY＋RTで特殊能力、Y長押しで「no items to interact with」、Y＋RT連打で採取・飲食のような音。これらを同じ入力と扱わず、他MODやキー割り当ての競合とは断定しない。今回の変更でその通知・音が解消すると確認されたわけではない。

## 変更する箇所

`LKS_KeenSensesPower [SPEL:800]` の効果条件から、`HasMagicEffect LKS_KeenSensesCooldownEffect == 0` を1件削除する。

以前は「自分の制御効果が存在しないときだけ、自分の制御効果を許可する」条件だった。条件が持続中にも評価される場合、制御効果は存在するだけで自身の条件を満たせない。条件をSPEL側に置いただけでは、この自己参照を避けたことにはならない。以前のコメントと検査はこの点を取り違えていた。

v0.1.2は使用者と種族の条件だけを残す。効果の有効時間60秒とNoRecastフラグによって、重複適用と再開始を抑制する設計にする。OnEffectStart内のプレイヤー・種族ガードも維持する。NoRecastの実際の挙動と再入力後の期限は、修正版の実機最終確認待ち。

## 維持する箇所と検査

- 既存レコードの上書き0件、4件の固有レコード、Skyrim.esmのみへのマスター依存。
- 制御MGEF、探知MGEF、内部SPELは公開済みv0.1.1とバイト単位で同一。
- PEXも公開済みv0.1.1と同一。PSCの変更は制御方法を説明するコメントのみ。
- 探知の赤色、Area 27、距離560 units、2秒と対象除外は変更しない。
- キー登録や通知・音の追加、他MODの設定変更、既存セーブの一括Dispelは行わない。

回帰検査は公開済みv0.1.1の実ZIPから記録したハッシュを基準にする。範囲・除外・描画・スクリプトを別の推測で変更しないための検査であり、ネイティブのタイマー動作を模擬して合格と扱うものではない。

## 更新

ゲームを終了し、MO2でv0.1.2を旧版へReplaceする。同じESP名、ローカルFormID、プロパティ、PEXを使う。能力を追加し直す必要はない。他の魔法効果を消すコマンドや他MODの無効化は必要ない。

確認手順は [IN_GAME_CHECKLIST.md](IN_GAME_CHECKLIST.md) の0/30/65秒の1回にまとめる。修正の狙いを説明したもので、再入力後の不発を解決済みと保証するものではない。
