# v0.1.4 diagnostic3：通常の発動で不発箇所を調べる

主能力800を直接Castしても光らず、同じ状態で内部探知803をCastすると光ったとの実機報告がある。探知表示は動くが、主能力の条件・起動スクリプト・制御からの実行を区別する必要がある。

diagnostic1/2で案内した `cqf` はユーザー環境で `not found` となった。Skyrimで使えることを確認せず案内した誤りであり、その手順は撤回する。**diagnostic3はコマンド入力不要。既存の「鋭敏な感覚」を通常どおり発動して診断する。** 修正済み本体ではない。

## 導入と実行

1. ゲームを終了し、このZIPをMO2に**別MODとして**導入する。本体v0.1.4も有効にしたまま、左ペインで診断MODを本体より下へ置く。意図して上書きするのは本MOD専用のPEX・PSC各2件だけ。
2. diagnostic1/2がある場合はそれを無効化するか、**診断MODだけをReplace**する。本体は置き換えない。診断MODを複数有効にしない。
3. 完全終了・再起動後、問題の検証用セーブをロードする。付け外しや事前の発動確認を挟まず、通常画面で65秒待つ。
4. 選択済みの「鋭敏な感覚」を **Y＋RTで1回だけ**発動する。`LKS DIAG3: INPUT START` が出たらOKで閉じ、続く診断画面またはエラーの内容を記録する。続く数値画面の名前は従来と同じ `LKS DIAG1`。
5. **何も出ない／最初の画面だけ出る**場合は、その結果を記録する。付け外し・連打・コマンドでの追加確認は挟まない。診断後はセーブせず終了する。

## 表示と影響

最初の画面は入力効果のOnEffectStartに入ったことを示す。次の数値画面はQuestのRunning状態、種族条件、探知SPELの参照有無、Native時計、保存した期限、実行前の残り秒数、TryActivateの戻り値、実行後の残り秒数を示す。途中で参照・対象・Quest開始・スクリプトのキャストに失敗した場合は、その箇所を示す文面を出す。

画面が出なかった場合も、適用条件・効果の寿命・保存された実行状態などを区別できたわけではない。最初の画面だけなら、入力イベントには入ったが次の報告までは完了していないと分かる。画面が出ない理由を特定のMODの競合と断定しない。

**Probeは現在と同じ制御を1回呼び、受理された場合は探知と通常のクールダウンを開始する。** 読み取りだけの診断ではない。Accepted=Trueは制御関数がTrueを返した意味で、描画の成功を証明しない。診断画面自体が入力処理の時間に影響する可能性があり、時計・画面・効果の寿命を含む実機動作は未確認。

本体のESP・レコード・コントローラーの元の処理・保存変数とプロパティは変更しない。入力スクリプトのOnEffectStartに表示と診断呼び出しを追加する。新しい保存変数・タイマー・OnPlayerLoadGame・Alias・装備変更はない。本体の保存状態への依存は残る。

診断が終わったらゲーム終了後に**診断MODだけを無効化**すると、元の本体PEXへ戻る。本体の削除・Resetは不要。LoreRimの案内に従い、セッション途中でロードしない。

## 制作・検査

`tools/build_diagnostic.py` は公開済みv0.1.4 ZIPのSHA256を固定し、そのPSCから診断用2スクリプトをstrictコンパイルする。保存レイアウト、コントローラーの元の全関数、入力の変更対象外の関数が同一であることを解析する。実際のPEXで、コントローラー4ケースと、入力からの準備完了・待機中・別種族・未設定SPEL・未設定Controller・Quest開始失敗・別対象の7ケースを模擬実行する。

Debug.MessageBoxは戻り値なしのコンパイル用宣言だけを使い、ゲームのDebug.pexは同梱しない。Mutagenによる両PEXの読み込み、ZIPのCRC・SHA256・同梱パスを検査する。実機の入力・時計・画面動作を模擬実行の合格で保証するものではない。

通常ビルドと同じツール・Wine環境で実行する：

```text
python3 tools/build_diagnostic.py --dotnet /workspace/scratch/dotnet/dotnet --caprica /workspace/scratch/caprica-bin/Caprica.exe --wine /workspace/scratch/wine-root/usr/lib/wine/wine64
```

ソースZIPには本体PSC・診断生成コード・検査用ホストを含む。再ビルドにはリポジトリの `dist/KhajiitKeenSenses-0.1.4-MO2.zip` も必要。公開済みZIPは上書きしない。
