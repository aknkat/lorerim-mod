# Estee Emerald Eyes 1.0.0

男性カジート用に、基準色 **#2EDB91** のエメラルド色の目を1種類追加します。RaceMenuでプレイヤーの目として選択します。元の目・NPC・顔や体の毛色・鋭敏な感覚の探知色は変更しません。

## 導入

1. ゲームを完全終了し、MO2で `EsteeEmeraldEyes-1.0.0-MO2.zip` を**新しいMODとして**導入します。鋭敏な感覚MODを置き換えるZIPではありません。
2. MO2左側で追加MOD、右側で **`EsteeEmeraldEyes.esp`** を有効にします。既存の目・顔関連MODの並び順は変更しません。Kalaの既存MODもそのまま残します。
3. 通常どおり起動・ロードし、コンソールの `showracemenu` でRaceMenuを開きます。**種族・性別は変更せず**、「目の色 / Eye Color」を切り替えて新しいエメラルド色の目を選びます。
4. 目の登録名は **`Estee Emerald 2EDB91`**。スライダー上の番号や名前の表示可否は環境によるため、固定番号は指定しません。末尾付近を含めて確認してください。
5. 外見を確定し、落ち着いた場所で別名保存します。再ロードはLoreRimの通常の注意に従い、ゲームを完全終了・再起動してから行います。

新しい目は最初から自動選択されません。元のプリセットは元の目を選び続けます。新しい目を選んだ状態でプリセットを保存した場合、そのプリセットは本ESPを参照します。

## 対象・依存関係

- プレイヤーの**男性カジート**を想定。使用可能種族は通常カジートと吸血鬼カジート。女性・他種族用の選択肢は追加しません。
- ESPの必須マスターは **Skyrim.esmのみ**。ESLフラグ付きESP、FormVersion 44。Skyrim SE 1.6.1170 / LoreRim環境向け。
- 選択操作には、既にLoreRimで使用しているRaceMenuを利用します。追加のSKSE DLL、スクリプト、クエスト、常駐処理はありません。
- 元画像・目の設定はユーザー提供の **Kala's Beast Eyes - Improved 2.0、1k版**を基準にしています。元MODを無効化する指示ではありません。

## 変更内容と干渉範囲

| 項目 | 内容 |
|---|---|
| 追加レコード | HDPT `800`、TXST `801`、FLST `802` の3件 |
| 既存レコードの上書き | 0件。RACE・NPC_・既存HDPT/TXST/FLSTを変更しない |
| 画像 | 本MOD専用パスのDDS1枚。1024×1024、BC7_UNORM、11段のミップマップ |
| 瞳孔・模様 | 元画像のHSL明度分布・黒い瞳孔・輪郭を維持し、色相と彩度を基準色に合わせる |
| アルファ | 圧縮前PNGでは元画像と同一。BC7は非可逆圧縮のためDDS再圧縮の微小差はある |
| 眼球モデル・モーフ | 現在の `EyesKhajiit.nif` / TRIを参照。NIF・TRIを同梱して上書きしない |
| 法線・反射 | 既存 `EyeArgonian_msn.dds` / `EyeArgonian_s.dds` と元のTXSTフラグを維持 |
| 顔・体・NPC | 変更・配布なし。NPCのFaceGen再生成は不要 |
| Requiem・生成パッチ | ゲームプレイ・種族レコードを変更しない。導入手順に生成パッチの再作成を含めない |
| 鋭敏な感覚 | 完全に別のESP。能力・探知色・範囲・消費に変更なし |

共有眼球メッシュ、共有の法線・反射画像、ENBと照明は現在のLoreRimの勝者を引き継ぎます。基準色#2EDB91の単色で眼球全体を塗るものではなく、元の模様の明暗を残すため、画面の各ピクセルがこのHEX値になる意味ではありません。発光の強さや反射を別途増やす変更はありません。

## 検査と未確認点

制作環境で、3件の新規レコード・マスター・内部参照・元の設定との差分・DDSの全ミップ構造と読み戻し・ZIPのパスとチェックサムを検査しています。別作者のESPパーサーによる読み戻しも行います。構造検査はゲーム内動作を保証しません。

**Skyrim / LoreRimでの実機動作は未検証です。** RaceMenuでの選択、まばたき、ENB下の色・反射、完全終了後のロードでの保持を実機で確認する必要があります。吸血鬼化・治療・変身時に選択が保持されるかも未確認です。

今回確認したのは以前提供されたMOD一覧、プリセット、Kalaの実ファイルです。すべてのMOD・生成パッチの中身やMO2仮想Dataの最終勝者を検査したものではありません。

## 解除

先にRaceMenuで**元の目に戻して確定・別名保存**し、ゲームを終了してから本MODを無効化します。新しい目を選んだまま取り外す前提にはしません。本MODを使ったプリセットを再利用する場合は、本MODを有効にするか元の目に選び直します。
