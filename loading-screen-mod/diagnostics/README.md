# ロード画面の読み取り専用診断

これはMODではありません。MO2にインストールせず、ZIPを通常のフォルダに展開してください。

1. ゲームの起動は不要です。MO2が開いていれば通常終了し、現在のプロファイルと優先順位を保存してください。
2. `Run-Diagnostics.cmd` をダブルクリックしてください。管理者権限は不要です。
3. 同じフォルダにできる `LoadingScreenDiagnostics-日時-識別子.zip` をチャットに添付してください。

標準の対象は `M:\LoreRim`。存在しない場合だけ対象フォルダを選択する画面が出ます。mods/profilesの場所はMO2のディレクトリ設定があれば使用します。

MODファイル、画像、MO2設定は書き換えません。作成するのは、この診断ツールのフォルダ内の結果JSONとZIPだけです。外部への通信・自動送信・ツールのインストールは行いません。CMDはこの実行プロセスに限ってPowerShellの実行ポリシーを指定し、永続設定は変更しません。

採取対象：各プロファイルの有効MOD名と優先順位、関連ESP名、共有画像DDSとEchoes/TESLのNIFの提供元・SHA256、関連するArchive設定とSSE Display TweaksのLoadScreen設定のみ。一般的な環境変数や認証情報、セーブファイルは採取しません。

MO2が保存した一覧からルーズファイルの優先元を推定します。ゲーム実行中のVFSそのものの観測やBSA内容の検査ではありません。旧DDS優先、新DDS優先、overwrite優先の3ケースをLinux PowerShell 7.4.6の模擬フォルダで検証し、対象ファイルが変更されないことを確認済み。Windowsのランチャーと実機MO2では未検証です。
